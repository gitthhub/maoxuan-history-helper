# 势力范围来源与绘制说明

本轮绘制参考时间：2026-10-15。数据位于 `src/territories.js`，共 75 个区域，关联 28 个势力条目。

## 表达方法

这些面是参考历史地图与文字叙述后，以省区、城市、山地和交通方向关系手工概括的示意轮廓，**不是从历史地图配准得到的 GIS 边界**。参考资料能够支持区域的大致位置和历史阶段，不能为每个顶点的经纬度提供测绘精度。轮廓不应导出用于面积统计、逐县归属判断或导航。

采用半透明填色和边线表达主要控制或影响范围，虚线红色区域包括根据地与游击活动区。日伪占领外缘与敌后根据地可以重叠，不能把占领面的内部理解成均匀实控。没有着色的地方表示本图未绘制，不表示没有政权或军队。

根据地、岛屿及分离的势力区域分别绘制；太原、大同在1949年初仍未易手，作为华北范围中的内部留白；青岛用沿海缺口和单独色块表达。图中边线、海岸和城市周围据点外缘均有明显概括，不能理解为当日工事或驻军的准确外缘。

## 图层与坐标

- 数据为 WGS84 近似参考坐标，顺序 `[纬度, 经度]`；与城市、事件数据一起转换后叠加至高德底图。
- `influence`：主要政军控制或影响区；`base`：根据地或解放区；`guerrilla`：含游击活动的敌后区域；`occupation`：日伪占领外缘概览。
- 面位于行军路线、篇目与事件标记下方。名称在缩放、移动时避让条目标记、浮层及其他名称；拥挤时部分名称隐藏，可以滚轮放大查看。
- 图例在地图左下角，时期概览在左上角；两者为半透明浮层，可以点击标题整体展开或收起。手机端初始收起为小按钮，桌面初始展开；切换时期保留手动选择的展开状态。图例只说明颜色，不触发地图缩放。右侧“时期势力”中的“在地图查看大致范围”仍可定位并高亮该势力，右上角可开关各图层。
- 色块弹窗保留同一个内容节点，展开来源时只重新计算布局，避免重建内容导致收起。弹窗使用独立的 Leaflet pane，位于浮层之上，并随地图移动同步位置。
